# Ylli — デジタルマーケティング戦略（進行中 R）

2026-09-30　／　Instagram と X での集客を前提に、認知 → フォロー → 購入 → 関係の継続までをひとつの仕組みにする。

## 0. 前提：語らない。見せる。
- **覚えてもらう対象：** 思想や主張ではなく、「見た瞬間に Ylli だと分かる視覚の型」。
  - Byron Sharp の「メンタル・アベイラビリティ」（買う場面で思い出されやすいブランドが選ばれる）を下敷きにする。
  - Jenni Romaniuk の「Distinctive Brand Assets（DBA）」（ロゴなしでもブランドだと分かる固有の要素）を下敷きにする。
- **文章のルール：** 外に出す文章は事実だけ（素材、寸法、仕様、製造工程）。形容詞、思想、キャッチコピーは使わない。

### 固有資産（DBA）
| 資産 | ルール |
|---|---|
| ① 45°の線 | 右下がりは太く、右上がりは消えるほど細い。構図とトリミングも45°系に揃える |
| ② 上から吊る構図 | 被写体は上端から始まり、下端には着かない。服も吊って撮る |
| ③ 一度だけの交差 | ひとつの画面に交差はひとつだけ |
| ④ 深青を一点だけ | 服の内側のテープ・裏地、画像の一辺か一点にだけ入れる |
| ⑤ 素・玄・鈍の色調 | 純白は使わず、明るさの幅を抑える |
| ⑥ 商品のひとつのズレ | 服に必ずひとつ入れる。説明はせず、写真に写っているだけにする |

- **確認方法：** ロゴを隠した投稿を第三者に見せ、Ylli と分かるかを定期的に確かめる。

## 1. STP
- **セグメント：** かつてモードに投資し、今は派手な服を選ばない層。年に数点を高い単価で選び、ロゴを嫌い、ディテールで判断する。
- **Jobs To Be Done：** 表面上は普通の服として通用しながら、自分だけが知っている差異を身につけていたい。
- **ポジショニング（社内用）：** 静かな上質ブランドと同じ品質に、設計上の破れをひとつだけ加える。
- **カテゴリーエントリーポイント：** 仕事用の服の買い替え、定番のシャツやパンツを探すとき、自分へのご褒美に1着。

## 2. ファネル（See / Think / Do / Care）
| 段階 | 目的 | 主なチャネル | KPI |
|---|---|---|---|
| See | フォロワー以外に届く | IG リール（テスト配信の機能も使う）、X の画像・動画、Pinterest、Meta 広告 | フォロワー外リーチ、3秒以上の視聴率、リーチあたりの送信数 |
| Think | 型を覚えてもらいフォローしてもらう | IG カルーセル、プロフィールのグリッド | 保存率、プロフィール訪問からのフォロー率 |
| Do | 登録と購入 | ウェイティングリスト、メール、発売日の告知、リターゲティング広告 | リスト登録率、購入率（CVR）、顧客獲得単価（CPA） |
| Care | 再購入と、購入者が次の客を連れてくる | 購入者向けの非公開チャネル、同梱物、イベント | リピート率、顧客生涯価値（LTV）、購入者の投稿数 |

- **North Star Metric：** 自社で直接連絡できるリストの人数（ウェイティングリスト＋メール登録者）。

## 3. コンテンツ（Hero / Hub / Hygiene）
- **Hero（年2〜3回）：** コレクションの発表、ポスターのシリーズ、展示、映像。
- **Hub（毎週の連載）**
  - HANG：吊った服の写真
  - PLATE：商品、図面、素材と寸法のカルーセル
  - INCIDENCE：図形の変換
  - PROCESS：製造工程。音と手元の映像だけ
- **Hygiene（常時）：** サイズ、素材、ケア、発売の予定、よくある質問、ハイライト。
- **投稿の比率：** HANG と PLATE 40% ／ INCIDENCE 30% ／ PROCESS 20% ／ 告知 10%。
- **Instagram の運用**
  - リールはフォロワー外へ、カルーセルは保存、ストーリーは既存フォロワーとの関係、と役割を分ける。
  - グリッドは 3:4 表示に合わせ、4:5 の投稿の中央 3:4 で型が成立するように作る。
  - 3×3 を1単位として並べる。
- **X の運用：** 思想ではなく画像と事実を置く（製造工程の記録、発売の告知、図形）。
- **Pinterest：** 追加を推奨。HANG と INCIDENCE の画像を再利用する。

## 4. コミュニティ（言葉ではなく合図）
- **所有の合図：** 服の内側に深青のテープと通し番号。同梱カードには番号と仕様だけを書く。
- **購入者の投稿の型：** HANG。撮り方だけを伝える。
- **購入者限定の場：** 親しい友達リストかブロードキャストチャンネル。図面、試作、先行購入を流す。
- **服以外のコンテンツ：** INCIDENCE の ZINE、ポスターのエディション、年1回の展示。

## 5. 集客の手段
- **Meta 広告：** 発売月から月10〜30万円程度。ターゲットは自動拡張に任せ、DBA が強い素材を週2本テストする。リターゲティングも行う。
- **シーディング：** 建築家、デザイナー、編集者、写真家など、フォロワー5千〜5万人のマイクロクリエイターに服を贈る。投稿は義務にしない。
- **CRM：** メールの自動配信を5本（登録直後／ウェイティングリスト登録／発売日／購入後のケア／再来訪）。文面は事実だけ。
- **売り方：** 受注生産と数量限定のドロップ。予約期間を「待つ時間」として体験の一部にする（意味は語らない）。

## 6. 計測
- **基盤：** Shopify、GA4、Meta ピクセルとコンバージョン API、UTM の規則。
- **振り返り：** 週1回、See → Care の各段階の数値を見る。
- **フェーズの切り替え条件（仮の数値）**
  - 保存率が安定して 3% を超えたら、開示期へ。
  - リストが 500人を超えたら、Collection 01 を発売。
  - リストの 3〜5% が購入し、90日以内のリピート率が 15% に届いたら、次のドロップの数量を増やす。

## 7. ロードマップ（12か月）
| 時期 | 内容 |
|---|---|
| 0〜2か月 | 視覚の型を定着させる、計測の基盤とメール配信を整える、ウェイティングリストの受付開始 |
| 3か月 | Collection 01 を受注生産で発売、展示、シーディング |
| 4〜6か月 | 購入者の HANG 投稿を循環させる、広告の最適化、ZINE 第1号 |
| 7〜12か月 | 第2弾のドロップ、定番の再販、セレクトショップ1〜2店への卸しを検討 |
