## 0. 進め方の前提（ユーザーの好み）

- **やり取りは日本語。** ポスター上のタイポグラフィは英語でよい（コム・デ・ギャルソンの告知ポスターのような白黒の英文組版がイメージ）。
- **求めているトーン**
  - ファッションブランドとして概念的なトーン。
  - テック、デジタル、AIっぽさ、サイバーは避ける。
  - ストリートの定番表現も避ける。
- **参照ブランドの扱い：** Rick Owens / PAF / JiyongKim などは「緊張感」の参考として挙がったもので、模倣はしない。
- **説明的なモチーフは避ける：** 「撚り＝糸」を描くのは安直だと却下された。何かを描写するのではなく、規則や関係で表す。
- **縦方向の力（吊られる・垂れる）は良いと評価されている。**
- **グラフィックは破壊的・実験的な方向を好む。**
  - ロゴは「添えるだけ」にしない。極端に振り切る（全面に出して壊す／極細の縦長／図形に溶かす）。
- **ストーリー（SNS）について**
  - 具体的な日付と会場は入れない。
  - 最新の指示では「文字なし・形だけ」で、実験的に作る。
- **成果物の渡し方：** 画像やPDFとして渡すことが多い。ファイル名は Foldering guide の規則に従う（§8）。
- **思想は語らない（2026-09-30 決定）**
  - 「違和感」や「ズレ」は、設計の内側にある概念として持つだけにする。言葉として外に出さない。
  - キャッチコピーや思想の発信は不要。例：「一度だけ、ずれた日常着」は却下された。
  - 表に出すとしても、視覚言語として出す。外に出す文章は事実だけ（素材、寸法、仕様、工程）。
- **引用元の扱い：** ポスターシリーズの思想（ポアンカレ、射影幾何、キュビスム）は、ユーザーが読んだ本からの引用。Ylli独自の展開は、洋服の考え方（型紙・縫い目・布目・型入れ）と結びつけて作る。
- **ブランドの立ち位置：** Fear of God が「ラグジュアリーな日常着」なら、Ylliは「少しズレのある日常着」。
  - 想定する人：若いころはギャルソンや Rick などモード系を着ていたが、今は派手さを求めていない大人。
  - その人が日ごろ感じる、ちょっとした違和感を着られる服にする。
  - この立ち位置の説明は社内用で、外に向けて言語化しない。
- **服以外の軸：** 服をメインにしつつ、同じ感覚を持つ人が集まる場も作る。つながりは言葉ではなく視覚の合図で作る。
- **マーケティング戦略：** `5_strategy/260930_ylli_marketing_strategy_R.md` を参照。

## 1. ブランド戦略（Part A）

出典：ユーザーのガイドライン草案 v0.2（`1_document/260214_ylli_bxguidelines_draft_v0.2.pdf`）。本文はユーザーのもの。

### A.1 Brand Name — Ylli（イリ）
- **由来：** 玄（xuán）＋ 撚り（Yori）。
- **撚り：** 複数の糸に回転を加えて束ね、一本の糸では得られない強度と構造を生む行為。「足す」のではなく「関係させる」ことで糸を変える。
- **玄：** 象形の起源は「束ねられ、吊り下げられた蚕糸」。そこから「暗い・深い・汲み尽くせない」の意味が生まれた。老子の「玄之又玄、衆妙之門」。
- **響き：** 日本語話者には撚り・糸との音の近さが聴こえ、そうでない話者には意味の固定されない開かれた音として響く。

### A.2 Brand Definition — 宙吊りの中に在り続けるための衣服
- 自己は固定された像ではない。服はこれまで「お前は何者か」への答えとして機能してきたが、Ylliはその装置にならない。
- 「不安を消さない。不安を増やしもしない。」 定まらないまま在ることを、衣服という形式で許可する。
- 一つの媒体では完成しない。触れられるものと触れられないもの、両方に触れた人の中でのみ、言語化できない何かが一瞬浮かぶ。

### A.3 Brand Essence — 玄に在ること
- 玄は到達できず、完成せず、説明できない。しかし玄の中に在ることはできる。
- 不安と自由が分離していない場所。

### A.4 Brand Story（要旨）
- 答えと自分のあいだの小さな隙間を、Ylliは埋めない。隙間は欠陥ではなく、自分が流動していることの最も正直な痕跡である。
- 完全には固定されず、崩れもせずに留まり続ける状態。その宙吊りの瞬間を、Ylliは「玄」と呼ぶ。

### A.5 Core Value
| | 価値 | 内容 |
|---|---|---|
| 流 | Fluidity | 変化を未完成と見なさず、流れ続ける状態を存在の自然な形として受け取る |
| 懸 | Suspension | 即時の結論を求めない。地面に着いていないが、落ちてもいない |
| 玄 | Depth | 関係の中で一瞬だけ浮かぶ、汲み尽くせないもの。名指しできない |

### A.6 Design Principle
1. **宙吊りを設えよ** — 確定しない余白を意図的に設計する。
2. **不在に気づけ** — 「何があるか」ではなく「何がないか」から設計する。
3. **意味を待て** — 即効性や分かりやすさを狙わない。

### A.7 Brand Identity System
- **定義（ブリーフでの表現）：** 「定まらない状態に、意味を与えずに関わり続けるための態度」
- **ブリーフでのキーワード：** Unfixed / Attentive / Enduring

**BIS の追加項目（〈案〉＝未承認）**
- **Vision〈案〉：** 定まらないまま在ることが、欠落ではなく一つの在り方として受け取られること。
- **Mission〈案〉：** 衣服と表現を通じて、答えを急がせない場所を設え続ける。
- **Tagline〈案〉：** 玄に在る。— Remain, unresolved.
- **Slogan〈案〉：** 太さは、向きが決める。（Collection 01）
- **Manifesto：** A.4 を正文とする。

## 2. ロゴシステム（B.1）— v1.0「平筆」

### コンセプト：太さは、向きが決める
- **書く規則だけを残したロゴ。** 45°に傾けた平筆（broad nib）で書いた線で、何かの形を描いてはいない。
- **太さは向きで変わる（ペン幅 L に対して）**
  - 縦の線：0.71 L
  - 右下がり「＼」：1.00 L（最も太い）
  - 右上がり「／」：ほぼ 0（髪の線）
  - 横の線：0.71 L
- **意味づけ：** 太さは線の性質ではなく、ペンとの関係で決まる。自己が固定された像ではなく、関係によって揺れ続けることの比喩。
- **一度だけ交わる：** 右下がりの太い線が、髪の線の上を一度だけ横切る。切れ目は入れない。
- **片方は地面に届かない（懸）：** 左の脚が右より短い。
- **縦に吊る：** 上端から吊られる形。大きさが変わるときに伸びるのは脚だけ。

### 構成と寸法（単位 L＝ペン幅）
- ペンの角度 45°
- 上端の脚 1.1 L
- 二本の間隔 2.9 L
- 交差の高さ 2.9 L
- 長い脚 8.1 L、短い脚 5.6 L
- 角丸 r = 1.1 L（自由曲線は使わない）
- 端の切り口：ペンの角度どおり 45°

生成コードの値は `L=16, LANE=46, TOP=18, R=18`、脚の長さは 130 / 90 です（`6_design/source/nib/geo.py`）。

### ロゴの種類（`6_design/logo/`）
- **symbol：** 基本形。
- **symbol_hang2 / hang3 / hang4：** 縦長の面用。脚だけを長くした形で、交差は常に一度。
- **symbol_absent：** 交差部分を抜いた形（Type C「不在」用）。
- **wordmark：** 同じ平筆で書いた「Ylli」。
- **signature_h：** 横組み。ワードマークの下端を、シンボルの短い脚の先端の高さに揃える。
- **signature_v：** 縦組み。ワードマークはシンボルの下に小さく、離して置く。ストーリーでの配置として承認済み。

### 使用ルール
- シンボルは面の上端から吊る（上端に接してよい）。下端には着けない。
- 余白：四方に 2.9 L。ただし上端だけは例外で、接してよい。
- 最小サイズ：
  - シンボル：10 mm / 48 px
  - ワードマーク：3 mm / 16 px
  - シグネチャー：8 mm / 40 px
  - 髪の線が消えることは許容する（不在）。
- **禁止**
  - 縦横比を変える
  - 回転させる、横に倒す
  - 等幅の単線に置き換える
  - 鈍の地や、コントラストの低い地に置く
- **ポスターでの例外（未承認）：** 破壊・変形・図形との混合は、ローンチ用ポスターの表現としてだけ使っている。ガイドラインに例外として追記するかは未決定。

## 4. 書体（B.3）
- **Noto Serif JP：** 和文・欧文の指定書体。
  - 見出し 500、本文 400、長い引用 300。
  - 明朝の抑揚が平筆のロゴと呼応する。
- **Noto Sans JP：** 補助書体。フォーム、価格、注意書き、11 px 前後の小さい文字。
- **等幅書体は使わない。** IBM Plex Mono はテックっぽさの原因として外した。
- **Archivo（Google Fonts の可変フォント。字幅 62–125、太さ 100–900）**
  - ローンチ用ポスターの英文ディスプレイ書体としてだけ使っている。
  - B.3 に正式に加えるかは未決定。
- ブランド名は必ずワードマークで表記する。「Ylli」を書体で組むのは本文中だけ。

## 5. グラフィック要素（B.4–B.6）

### キービジュアル（糸を描かない）
- **Type A　懸：** 上端から吊られた縦線の列。長さだけが違い、その中に交差（シンボル）が一度だけ現れる。
- **Type B　交：** 交差の一点だけを大きく切り取る。太い線と、消えかけた髪の線。
- **Type C　不在：** 交差を抜いたシンボル。前と後だけを残す。

### アイコン（10種）
- **描き方：** ロゴと同じ平筆で描く。24 px のグリッドで L = 2.3。
- **種類：** home / search / bag / account / menu / close / arrow / plus / hanger / store。
- **使わない表現：** 角丸・塗りつぶし・影。

### 写真
- 縦位置のみ。身体は画面の上下で切れる。
- 低照度（玄）。
- 顔を正面から写さない。
- 小物で説明しない。
- ロゴを写真の上に置かない。

## 7. コミュニケーション（ローンチ）

### ポスター（`6_design/poster/`、B2 比率）
- **テーマ：ズレ（認識のずれ）**
  - 文字の輪郭を図形として取り出し、離しても文字として成立するか、近づきすぎるとどうなるかを問う。
  - 書体は Archivo 900、字幅 62。
- **Z01 SHIFT：** 採用した方向性。
  - ロゴを紙より大きく出し、横の帯に切って下ほど大きくずらす。
  - 「SHIFT」の文字は同じ帯で逆向きにずらし、重なった部分は白く抜ける。
- **最終形はペアで使う**
  - `poster_shift_inplace`：崩す前
  - `poster_shift`：崩した後。帯の高さは不規則なリズムで、ずれは加速度的に大きくなり、一部の帯は横に伸縮する。元の輪郭を細い線で残し、右端にずれ量の注記を入れる。
- **Z02〜Z05：** 同じシリーズの別案。
  - Z02 APART：ロゴは極細の縦長
  - Z03 TOO CLOSE：ロゴは図形に溶かす
  - Z04 FORM：ロゴは図形に紛れる
  - Z05 UNRESOLVED：ロゴは全面・反転
- **日付と会場は入れない。**

### インスタストーリー（`6_design/sns/`、1080×1920）
- **signature_k / w**
  - シンボルは上端から吊り、高さは約1040 px。
  - ワードマークは幅180 px、上から約1490 px の位置に小さく離して置く。
- **shift_inplace / shift：** ポスター Z01 のペアを 9:16 で組み直したもの。
- **INCIDENCE 01–06：** 最新版。文字なし・形だけの実験版。
  - **発想**
    - アンリ・ポアンカレの考え方を下敷きにしている。空間は視覚だけでなく、運動や触覚から組み立てられるという考え方。
    - 射影幾何も参照している。射影では長さも角度も失われるが、「二本の線が交わっている」という関係（接合＝incidence）だけは残る。
    - ロゴの「一度だけ交わる」がこの不変量にあたる。「形は残らないが、関係は残る」。
    - ストーリーをタップして進む行為を、見る人自身の運動として扱う。形の変化はコマとコマの間で起き、目はその途中を捉えられない。
  - **各コマ**
    - 01 project：消失点から放射状に広がる縞と重ね、ロゴは縞の白黒の反転としてだけ現れる。
    - 02 simultaneity：7つの視点からの投影を同時に重ねる（キュビスム的な同時性）。
    - 03 join：6×4の表。合わせる形とブール演算（合わせる／重なりを抜く／引く）の組み合わせ。
    - 04 multiply：回転しながら縮む射影を26回繰り返した渦。
    - 05 vanish：正面から真横まで回転する過程を28回の多重露光で並べる（マレーの連続写真的）。
    - 06 remains：交差点だけを星座のように残す。

## 7.5 ホームページ（試作、2026-09-30）
- **ファイル：** `6_design/web/260930_ylli_web_top_R.html`
- **プレビュー（claude.ai、非公開）：** https://claude.ai/artifact/PC9c4RmCidFjdPnisfD8N3
- **考え方：** Ylli 独自の解釈で、洋服の作り方と結びつけた。
  - シンボルを型紙のように6ピースに分けて扱う。
  - 服は布の形ではなく「縫い目＝どこでつながるか」で成り立つ。その考え方で、ロゴがどこで認識されているかを見せる。
- **スクロールの4段階**
  1. Sewn：正しいロゴ。
  2. Cut / displaced：スクロールするほどピースがずれる。スクロールの速さでも揺れる。縫い目の点は点線でつながったまま。
  3. Marker：ピースが布目方向に回転し、布の上に型入れされる。
  4. Joint：交差する2ピースだけが元の位置でつながり直し、深青の円が付く。他のピースは鈍に退く。
- **表示の約束：** 最大のズレ量を mm で表示し、段階名を併記する。思想は文章では書かない。
- **下の各セクション**
  - Collection 01：8点の技術画（平面図）。各プレートのズレの箇所だけを深青にし、仕様を数値で書く。
  - Marker：型入れの図。
  - Information：ウェイティングリスト、受注生産、通し番号。
- **仮置きのまま：** 素材、価格、連絡先、ウェイティングリストの送信先。

   - brrranding.com を参考にケーススタディ形式でブラッシュアップした（サイト自体はネットワーク制限で閲覧できなかった）。

3. **v5 HODOKE v0.2：** ユーザーのマーク（二本の糸が一度交差する）でシステムを作った。「独自性がなく、ありきたり」との評価だった。
   - 改良案 P0〜P4 を出し、P3（太い糸と細い糸・縦長）が一度承認された。
4. **P3 の却下：** 「テック企業のようにデジタルっぽい」「撚る＝糸が安直」という理由。ただし縦方向の力は良いと評価された。
5. **v1.0 平筆：** 上記を受けて採用した現在のロゴ。
   - 描写をやめ、「45°の平筆で書く」という規則にした。
   - 構造（二本・一度の交差・縦長・脚の長短）は P3 から引き継いでいる。
   - ユーザーの評価は「大分イイ感じ」。
6. **ポスターの変遷**
   - v8：英文タイポグラフィの6枚。
   - ユーザーから「もっと文字を歪ませる」「図形を取り入れる」「テーマはズレ」「ロゴは振り切る」と指示があった。
   - v9：ズレの5枚を制作。Z01 の方向が選ばれ、複雑なリズムにブラッシュアップした。
7. **ストーリーの変遷**
   - シンプルなロゴの版と SHIFT の版を作った。
   - 次にポアンカレを参照した INCIDENCE を作った。
   - ユーザーの指示で日付と会場を削除し、文字も削除し、さらに実験的な方向へ進めた。
